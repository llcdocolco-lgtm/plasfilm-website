# /preview
Levanta un servidor local para previsualizar el proyecto actual.

Pasos:
1. Detecta en qué carpeta estás (srdev-marca/, portafolio-servicios/, o plasfilm/)
2. Ejecuta: npx serve . -p 3000
3. Si el puerto 3000 está ocupado, usa 3001 o 3002
4. Imprime: "✅ Preview en http://localhost:300X — abre en tu browser"
